# 设计

aria2 跑在别的机器上（NAS、路由器、服务器），本程序只是它的托盘客户端：看速度和进度，暂停、继续、移除，新建下载。本机不运行 aria2。进度和待办在 `plan.md`，取舍理由在 `decisions.md`。

## 1. 分界线

| aria2 决定 | 程序决定 |
|---|---|
| 有哪些任务、状态、速度、进度、文件、出错信息 | 窗口、布局、控件、动画、托盘图标 |
| 下载目录（全局选项 `dir`）、并发数等全部下载选项 | 刷新频率、面板尺寸、界面语言、开机启动、通知开关 |

程序不改 aria2 的全局选项，不读写 aria2 的配置文件。新建下载只带「保存到」一个选项，默认值取 aria2 的 `dir`。

## 2. 连接

- 地址填 aria2 的 RPC 地址（`http://主机:6800/jsonrpc`），程序换成同一端口的 WebSocket（`ws://…/jsonrpc`；`https` 换成 `wss`）。也可以直接填 `ws://`。
- 密钥（`rpc-secret`）按当前 Windows 用户用 DPAPI 加密保存，每个调用的第一个参数是 `token:密钥`。
- 一个 WebSocket 连接同时用来调方法和收通知；调用按 id 配对。断线后 1、2、5、10 秒退避重连。
- 保存设置前先真连一次（`aria2.getVersion`），连不上、密钥不对，就在设置窗口里说清楚。

### 刷新

aria2 只推事件（开始、暂停、停止、完成、出错），不推速度和进度，所以要定时取。每次用一个 `system.multicall` 取全部：

| 面板 | 间隔 | 取什么 |
|---|---|---|
| 开着 | 1 秒 | `getGlobalStat`、`tellActive`、`tellWaiting(0, 100)`、`tellStopped(0, 100)` |
| 收起 | 2 秒 | `getGlobalStat`、`tellActive`（托盘提示和进度环要用） |

只取用得到的字段（`keys` 参数）。详情页另取这个任务的 `files`。收到事件马上补取一次，不等下一轮。

### 通知

- 普通下载：`aria2.onDownloadComplete` 时弹「下载完成」。
- BT：`aria2.onBtDownloadComplete`（下完、开始做种）时弹；之后做种结束的 `onDownloadComplete` 不再弹。
- 出错：`aria2.onDownloadError` 弹「下载出错」，带 aria2 的出错信息。
- 磁力链接先下种子信息，这个任务完成后接着生成真正的任务（`followedBy` 不空）：它不弹。
- 通知用托盘图标的气泡（`Shell_NotifyIcon` 的 `NIF_INFO`），Windows 10 / 11 显示成系统通知。点通知弹出面板。设置里能关。

## 3. 托盘图标

- 单色，跟着任务栏深浅色变白或变黑。
- 没有下载中的任务：一个「向下箭头落到托盘上」的图形。
- 有下载中的任务：箭头缩小放在中间，外面一圈进度环。环的底槽淡色，已完成的部分实色，从 12 点钟方向顺时针走。
  - 总进度 = 全部下载中任务的已下载之和 ÷ 总大小之和。大小还不知道的任务（总大小是 0，比如刚开始取种子信息）不算进去。
  - 做种中的任务（BT 已下完）不算下载中。
- 图标由程序画（`Ui/TrayArt.cs`），每次进度变化超过 1% 才换图标。
- 鼠标悬停：`↓ 12.3 MB/s  ↑ 1.2 MB/s`，第二行 `3 个下载中`。连不上时写「连不上 aria2」。
- 左键：弹出 / 收起面板。右键菜单：打开面板、全部开始、全部暂停、设置…、开机时启动、退出。

## 4. 面板

固定尺寸，默认 380 × 560，在设置里改。内容超出时在面板里滚动。

```
┌──────────────────────────────┐
│ ↓ 12.3 MB/s  ↑ 1.2 MB/s ⇅ + ⏸│  顶栏：全局速度；排序、新建、全部暂停 / 全部开始
│ ╭────────────────────────────╮│
│ │ ▁▂▄▆█▇▅▃▂▁   最近 60 秒     ││  速度曲线：下载实色、上传淡色
│ ╰────────────────────────────╯│
│ ⌄ 下载中 · 2                ⏸  │  分组标题，右边是组操作
│ ┌──────────────────────────┐  │
│ │ ⬇ ubuntu-26.04.iso   ⏸  ✕ │  │  任务卡片
│ │ ━━━━━━━━━━━━━──────────── │  │  进度条
│ │ 1.2/3.4 GB · 35%   12 MB/s · 3 分钟│
│ └──────────────────────────┘  │
│ ⌄ 等待中 · 1             ▶  ⏸  │
│ › 做种中 · 21 · ↑ 33 KB/s ⏸ ⏹  │  每组都能收起；做种默认收起
│ ⌄ 已完成 · 32               ⌫  │  清除
│   …（一页 10 张卡片）          │
│        ‹  1 / 4  ›             │  分页
└──────────────────────────────┘
```

### 顶栏

- 左边：下载速度（17 号半粗）和上传速度（13 号，次要色）。
- 右边：排序菜单；「+」新建下载；「全部暂停」（有下载中或等待中的任务时）或「全部开始」（全都暂停了时）。
- 排序菜单：默认顺序（aria2 给的）、名字、大小、进度、速度，下面一段升序 / 降序，当前的打勾，存在设置里。每组各自按它排；值相同时保持 aria2 的先后。名字按自然顺序（第 2 集在第 10 集前面），不分大小写。速度：做种的按上传，其余按下载。
- 顺序只在整页重建时重排（打开面板、翻页、收起展开、改排序、任务增减），每秒的原地更新照上次排好的顺序：按速度、进度排时顺序每秒都在变，卡片跟着跳就点不中，提示框也弹不出来。

### 速度曲线

- 一张卡片，高 64，画最近 60 秒的下载速度（强调色的线加淡填充）和上传速度（次要色的线）。
- 纵轴按这 60 秒里的最大值自动缩放，右上角小字写这个最大值。
- 面板收起时照样记（每 2 秒一个点，补成每秒）。

### 任务卡片

| 行 | 内容 |
|---|---|
| 第一行 | 类型图标（BT 是两个人，表示对等下载；普通下载是文件），文件名，右边按钮：暂停 / 继续，移除 |
| 第二行 | 胶囊进度条，高 6，圆角 3。下载中填强调色，暂停和等待是次要色，出错是警告色，完成是绿色 |
| 第三行 | 左：`已下载 / 总大小 · 百分比`；右：`速度 · 剩余时间`。暂停写「已暂停」，等待写「等待中」，出错写出错信息，做种写 `做种中 · ↑ 速度` |

- 文件名：BT 用种子里的名字（`bittorrent.info.name`）；否则用第一个文件的文件名；还没有文件名时用链接的最后一段；种子信息还没下来时写「正在取种子信息」。
- 文件名一行；放不下时像 macOS 那样从中间省略（`ubuntu-26.04-des…-amd64.iso`），开头和结尾都看得见。悬停显示缩略图（有的话）和全名。出错信息放不下时也是悬停看全。
- 点卡片（除按钮外）进详情页。
- 右键弹菜单，每次弹出时按任务当时的状态排：详情；暂停 / 继续；等待中的「移到队首」「移到队尾」（`aria2.changePosition` 的 `POS_SET 0` / `POS_END 0`）；打开文件、打开文件位置（见下面「打开文件」）；复制名字、复制链接（BT 用信息哈希拼磁力链接，其余是第一个文件的下载地址）、复制保存位置；移除（做种中的叫「停止做种」）。菜单限制在面板窗口里弹，开着时面板不收。

### 打开文件

- aria2 给的是它那台机器上的路径（比如容器里的 `/downloads/…`），程序换成本机路径：「aria2 上的下载目录」开头的换成「下载目录在这台电脑上的位置」（一般是 NAS 的共享文件夹或映射的盘符，如 `\\nas\Download`、`Y:`），斜杠换成反斜杠。按整段目录比，`/downloads` 不匹配 `/downloads2`。「aria2 上的下载目录」留空就用 aria2 自己的全局下载目录（连上后取 `getGlobalOption` 的 `dir`），只有任务存在别处时才要填；本机那一边程序猜不出来（不知道这台电脑用什么共享名、盘符访问 NAS），要用户填。
- 打开的是：BT 的「保存位置/种子名」（单文件种子就是那个文件，多文件种子是那个文件夹）；其余是第一个文件。
- 「打开文件」交给 Windows 用默认程序打开；「打开文件位置」开资源管理器并选中它。打开后面板收起。
- 没设本机的下载位置、路径不在那个目录下、文件不存在：横幅写原因；没设本机的下载位置的横幅带「打开设置」按钮。查文件在不在放到后台线程（网络路径连不上时要等几秒）。
- 详情页的按钮也有「打开」「位置」。
- 「移除」：下载中、等待中的调 `aria2.remove`；已完成、出错的调 `aria2.removeDownloadResult`。只是从 aria2 的列表里拿掉，已下载的文件留在原处（aria2 本来就不删文件），所以不确认。
- 分组：下载中（`active` 且不是做种）→ 等待中（`waiting`、`paused`）→ 做种中（`active` 且 BT 已下完）→ 已完成（`complete`、`error`、`removed`）。默认顺序：下载中、等待中、做种中照 aria2 给的，已完成的新的在前；可以改排序（见「顶栏」）。
- 每组的标题都能点着收起 / 展开，标题前面一个箭头（收起朝右、展开朝下）。默认只有「做种中」收着，它的标题另写这一组的总上传速度。程序运行期间记着每组收没收。
- 组操作：标题右边的小圆图标按钮（直径 22），点了不收起这一组。按组里有什么状态的任务出：

| 组 | 按钮 |
|---|---|
| 下载中 | 全部暂停 |
| 等待中 | 全部开始（有暂停的时）、全部暂停（有排队的时） |
| 做种中 | 全部暂停；停止做种（逐个 `aria2.remove`，任务进「已完成」，文件留着，再做种要重新加种子）。停止做种要确认：点一下按钮变成红底的「停止做种？」，4 秒内再点一下才执行 |
| 已完成 | 清除（`aria2.purgeDownloadResult`） |

  逐个发命令，第一个失败就停下，横幅写原因。暂停的做种任务会挪到「等待中」（aria2 里是 paused）。
- 分页：每组一页最多 10 张卡片，多了在这一组下面出「‹ 2 / 5 ›」。每组的页码各记各的，程序运行期间记着；任务变少时退到最后一页。
- 磁力链接取完种子信息的中间任务（`followedBy` 不空）不列：它接着变成了真正的下载，列出来只是重复。
- 详情页里，速度和连接数只在活动中时有数值，其余状态写「—」。路径、哈希、出错信息太长时折行。
- 一个任务都没有：写「没有下载任务」，下面一个「新建下载」按钮。

### 详情页

- 顶栏换成返回按钮加「详情」。
- 第一张卡片：最上面是缩略图（见下面「缩略图」，圆角 10，最高 200，取不到就不占地方），然后是完整的文件名（14 号半粗，折行，能选中复制），下面是大号进度：百分比（40 号细体）和进度条。

### 缩略图

- 向 Windows 要下载到的文件的缩略图（和资源管理器里看到的同一张），路径按「打开文件」一样换成本机路径，所以要先设好「文件位置」。
- 只要真缩略图：Windows 给回来的是文件类型图标（不是视频、图片，或者文件没下完生成不出）就当没有，只显示名字。
- 两处：卡片上悬停名字时，提示框上面是缩略图（最大 320 × 200）、下面是全名，提示框弹出时才去取；详情页第一张卡片顶上。
- 按「本机路径 + 尺寸 + 任务状态」记在内存里（没有的也记，免得每次悬停都去 NAS 读），最多 300 个；任务状态变了（比如下完了）会重取。
- 属性列表（系统设置那种分组列表）：状态、大小、已下载、下载速度、上传速度、剩余时间、连接数、保存位置；BT 另有做种者、分享率（已上传 ÷ 已下载）、信息哈希；出错时有出错代码和信息。
- 文件列表：每个文件一行，文件名（相对保存位置）、大小、进度。
- 按钮：暂停 / 继续、移除、打开、位置（后两个在知道路径时才有）。

### 新建下载

- 顶栏换成返回按钮加「新建下载」。
- 一个多行文本框：每行一个链接（http、https、ftp、磁力链接）。打开这页时，剪贴板里是链接就先填上。
- 「添加种子文件」按钮选 `.torrent`；也可以把 `.torrent` 拖到面板上（任何一页拖进来都直接进这一页）。
- 「保存到」文本框，默认是 aria2 的 `dir`，空着就用 aria2 的默认值。这是 aria2 那台机器上的路径。
- 「开始下载」：每行链接一个 `aria2.addUri`，每个种子一个 `aria2.addTorrent`。成功后回主界面；失败的留在框里，按钮上面写出错信息。
- 选文件对话框开着时面板不收起。

### 二级页的进出

- 左上角返回、按 Esc、面板收起，都回到主界面。
- 窗口尺寸始终不变。

### 连接状态

- 没设置：占位页写「还没设置 aria2 的地址」，带「打开设置」按钮。
- 连接中：转圈加「正在连接 aria2…」。
- 连不上：转圈加「连不上 aria2，正在重试…」和出错原因。
- 密钥不对：「密钥不对，请在设置里重新填。」，带「打开设置」。
- 连上过又断开：顶栏下面出横幅（没有 ✕，连上了自己消失），内容保留最后一次的值，按钮不能点。

## 5. 界面

照 HA Tray 的风格（接近 macOS 控制中心）：

- 窗口无边框，总在最前，失焦就收起，贴着任务栏，背景是 Win11 亚克力；外框圆角由系统决定。
- 跟随 Windows 的深浅色和强调色。
- 卡片半透明白（深色约 7.5%，浅色约 62%），圆角 14，内边距 10，卡片之间隔 8，不画边框。
- 文字三级：主文字、次要（约 55%）、更淡（约 32%）。字体 Segoe UI Variable，中文回退微软雅黑。正文 13，小字 11。
- 图标用系统自带的 Segoe Fluent Icons（Windows 10 回退 Segoe MDL2 Assets），不带图标字体。
- 卡片上的小按钮：直径 26 的圆，灰底；悬停变亮，按下更亮，不可用变淡。
- 数字用等宽数字（`tabular-nums`），速度每秒变时文字不左右跳。
- 滚动条照 WinUI 默认的样子：盖在内容上，鼠标在面板里动、滚动时出现细条，悬停变粗可以拖，停下后淡出。内容右边留 12，滚动条落在这段边距里。
- 提示框（全名、按钮名）的文字变了才重设；每秒都重设的话提示框弹不出来。
- 横幅卡片：顶栏下面一张圆角 12 的卡片，左边警告色图标，中间一句话（折行、能选中），右边可以有一个强调色的动作按钮（如「打开设置」）和 ✕；图标、文字、按钮都按整行竖直居中。命令失败、要用户去做的事都用它，不自己消失，点 ✕ 或面板收起时清掉；断线的横幅没有 ✕，连上了自己消失。
- 图标和同一行的文字竖直居中对齐（调试通道 `align` 查）。

## 6. 设置

- aria2 RPC 地址、密钥、文件位置（下载目录在这台电脑上的位置；aria2 上的下载目录，留空用 aria2 的）、界面语言（自动 / 中文 / English，「自动」跟 Windows 显示语言）、面板尺寸、下载完成时通知、开机时启动。
- 单实例运行。参数：`--demo`（内置假数据，不连 aria2）、`--debug`（文字调试通道）、`--lang=zh|en`（只管这一次运行的界面语言）。

## 7. 调试通道

`--debug` 时往 `%LOCALAPPDATA%\Aria2Tray\debug-cmd.txt` 写一行命令，结果在 `debug-result.json`。不截图。

| 命令 | 作用 |
|---|---|
| `dump` | 连接状态、全局速度、每个任务的模型和显示出来的文字、托盘提示和进度环 |
| `show` / `hide` | 弹出并保持打开 / 收起 |
| `detail <gid>`、`add`、`back` | 切页面 |
| `page <组> <页>` | 翻页，组是 `downloading`、`waiting`、`seeding`、`stopped`，页从 1 起 |
| `fold <组>` / `unfold <组>` | 收起 / 展开一组 |
| `menu <gid>` | 这个任务的右键菜单有哪几项，加上它在 aria2 上的路径、换成的本机路径、复制出去的链接 |
| `sort <方式> [desc]` | 只在这次运行里改排序，不存设置；方式是 `default`、`name`、`size`、`progress`、`speed` |
| `texts` | 当前页面上的全部文字（查中英混杂、查注释性质的文字） |
| `layout` | 每个文字块有没有被截断（从中间省略的另列）、有没有元素超出面板宽度、元素之间有没有重叠 |
| `align` | 每个图标和同一行文字的竖直中心差多少（只报差 0.5 以上的）。量的是两者的框，字形本身在框里偏不偏量不出来，要用户看 |
| `open <gid>` | 照「打开文件」走到查文件在不在为止，报本机路径和在不在，不真打开；出错时横幅照常出来 |

## 8. 界面文字

照 HA Tray：界面上只写名字、读数、状态、按钮上的动作和要用户知道的错误，不写解释程序做法的说明，提示框也一样。需要说明的写在本文档里。
