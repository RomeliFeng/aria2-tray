# 决策记录

只增不改；被推翻的标「已取代」。

## 2026-10-18 只做远程 aria2 的客户端，WinUI 3 + .NET

- 用户的 aria2 跑在 NAS 上，现成的 Windows 客户端要么自己带 aria2 跑（Motrix Next、商店里的 aria2 UI），要么是整窗口的网页界面（AriaNg Native），没有轻量的托盘客户端。
- 技术栈和 HA Tray 一样（WinUI 3 + .NET 10，不打包，Windows App SDK 运行时随程序带上）：亚克力背景、控件风格和 Win11 一致，用户维护一套就够。
- 托盘、窗口、控件套件、设置、调试通道的代码从 HA Tray 复制过来再改，不抽成两边共用的库：两个程序各自演进，改一边不牵连另一边。

## 2026-10-18 用 WebSocket，定时取速度

aria2 的 RPC 有 HTTP 和 WebSocket 两种，在同一个端口。用 WebSocket：一个连接既能调方法又能收事件，下载完成、出错的通知不用靠轮询去猜。速度和进度 aria2 不推，照样定时取，用 `system.multicall` 一次取完。

## 2026-10-18 通知用托盘气泡，不用 AppNotificationManager

不打包的程序用 Windows App SDK 的通知要注册 COM 激活器和 AUMID，点通知时还可能另起一个进程。托盘图标本来就有，`Shell_NotifyIcon` 的气泡在 Windows 10 / 11 上就显示成系统通知，点了回到本进程（`NIN_BALLOONUSERCLICK`），几十行代码。

## 2026-10-18 托盘图标画总进度环，由程序画

用户选的。图标由程序按当前进度现画（32 位带透明的位图转 `HICON`），不预先生成一套图：进度是连续的，深浅色两套各一百张不划算。程序图标（窗口、exe）还是由 `tools\make-icons.ps1` 生成。

## 2026-10-18 做种单列一组、分页、名字从中间省略

接用户的 aria2 看真实数据：21 个活动任务全是做种，已完成几十个，文件名普遍很长（集数和哈希在中间、结尾）。用户定了：
- 做种单列「做种中」一组，默认收起。aria2 里做种也是 `active`，和真在下的混在一起时，真在下的被埋掉。
- 每组都能收起：起初只有「做种中」能收，用户去点「已完成」的标题没反应。（已取代：见「分组改成标签页」）
- 每组有组操作按钮，统一用小圆图标（「清除」原来是文字链接，用户要求换成图标）。做种组两个都要：全部暂停（还能继续，但会挪到「等待中」）和停止做种（`remove`，要重新加种子才能再做种，所以点两下确认）。
- 排序：顶栏一个菜单，存在设置里。顺序只在整页重建时重排，不每秒跳。
- 详情页显示完整的名字：顶栏一行放不下，用户嫌「明明有空间也不显示全」；顶栏改成「详情」，名字放进第一张卡片折行显示。
- 每组分页，一页 10 个（先试 5 个，用户嫌少）。
- 名字放不下时照 macOS 从中间省略，悬停看全名。WinUI 的 TextBlock 只能从尾巴省略，所以自己量字（`Ui/Parts.cs` 的 `MiddleText`）。
- 滚动条要看得见：原来照 HA Tray 藏掉了，用户不知道滚到了哪里。HA Tray 藏它是因为网页里的滚动条占宽度；这里的滚动条盖在内容上，不占宽度，没有藏的理由。

## 2026-10-18 分组改成标签页（取代「每组都能收起」）

用户评审时觉得四组竖着排不合适：做种和已完成动辄几十个，即使能收起、能分页，也要来回滚动、展开收起。改成速度曲线下面一排标签（分段控件），一次只看一组；收起去掉了。默认显示上次选的标签（存在设置里），用户选的。每页个数也放进设置（用户要求）。

## 2026-10-18 右键菜单；打开文件靠「文件位置」映射

用户要右键菜单，并且能直接打开文件、打开文件位置。文件在 aria2 那台机器上，aria2 只给它自己的路径（容器里是 `/downloads/…`），程序猜不出这台电脑怎么访问它，所以设置里让用户填一组映射（aria2 上的目录 → 本机位置，一般是 NAS 的共享文件夹）。不自动猜共享名：猜错了就是打开错的地方。
- aria2 那一边留空就用 aria2 的全局下载目录（`getGlobalOption` 的 `dir`）：起初两边都要填，用户问程序明明取得到为啥还要填。

## 2026-10-18 缩略图向 Windows 要

用户问视频能不能显示缩略图，要放在悬停提示和详情页里。不自己解码视频：Windows 的缩略图（`StorageFile.GetThumbnailAsync`）就是资源管理器用的那一套，NAS 上的 mkv 实测能出（第一次约 0.6 秒，之后有缓存）。只认 `ThumbnailType.Image`，Windows 退回成文件类型图标的当没有。

## 2026-10-18 提示改成横幅卡片

原来是顶栏下面一行黄字、6 秒后消失，用户说这个形式不行。从「横幅卡片」「底部弹出的对话块」「系统通知」里选了横幅卡片：带图标、带动作按钮（比如「打开设置」直接去改），不自己消失，点 ✕ 关。

## 2026-10-18 图标用 Segoe Fluent Icons

HA Tray 带 Material Design Icons 字体，是因为 HA 的图标都是 mdi 的名字。本程序用到的图标只有十来个（暂停、继续、移除、新建、磁铁、文件……），系统字体里都有，不带字体，发布包小一些。
