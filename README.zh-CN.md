# Aria2 Tray

Aria2 Tray 是 [aria2](https://aria2.github.io/) 的 Windows 托盘客户端，aria2 跑在别的机器上，比如 NAS、路由器或服务器。点托盘图标，任务栏上方弹出面板，显示全局速度和全部下载任务；面板失去焦点时自动收起。样式参照 macOS 控制中心。

Aria2 Tray 本身不运行 aria2，它经 WebSocket 连 aria2 的 JSON-RPC 接口。

[English](README.md)

## 功能

| 功能 | 说明 |
|---|---|
| 托盘图标 | 进度环显示全部下载中任务的总进度；悬停显示下载和上传速度 |
| 速度曲线 | 最近 60 秒的下载、上传速度 |
| 任务列表 | 下载中、等待中、做种中、已完成四个标签，记住上次选的；分页，每页个数在设置里改；每个任务显示进度、大小、速度和剩余时间；名字太长时从中间省略，悬停看缩略图和全名 |
| 缩略图 | 下载好的文件的缩略图（由 Windows 生成），在悬停提示和详情页里；要先在设置里填「文件位置」 |
| 右键菜单 | 详情、暂停或继续、移到队首或队尾、打开文件、打开文件位置、复制名字 / 链接 / 保存位置、移除 |
| 排序 | 默认顺序、名字、大小、进度、速度，升序或降序 |
| 操作 | 暂停、继续、移除任务；整组暂停、整组开始；停止做种；清除已完成 |
| 详情 | 状态、大小、速度、连接数、保存位置、做种者、分享率、信息哈希、出错信息、文件列表 |
| 新建下载 | 链接和磁力链接（每行一个）、`.torrent` 文件；文件和链接可以拖到面板上；剪贴板里的链接自动填入 |
| 通知 | 下载完成或出错时弹系统通知 |
| 外观 | 跟随 Windows 的深浅色和强调色 |

## 运行要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 2004（内部版本 19041）或更新；推荐 Windows 11 |
| 运行时 | [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0) |
| aria2 | 打开 RPC（`enable-rpc=true`），本机能连到（`rpc-listen-all=true`） |

## 设置

1. 运行 `Aria2Tray.exe`，第一次运行时会打开设置窗口。
2. 填 RPC 地址，例如 `http://192.168.1.10:6800/jsonrpc`；也可以填 `ws://`、`wss://` 地址。
3. aria2 设了密钥（`rpc-secret`）就填上。密钥只保存在本机，按当前 Windows 用户加密（`%LOCALAPPDATA%\Aria2Tray\settings.json`）。
4. 要在这台电脑上打开下载好的文件，就在「文件位置」里填下载目录在这台电脑上的位置（例如 `\\nas\Download` 或映射的盘符）。aria2 那一边的下载目录会自动取到，任务存在别的目录时才要填。
5. 保存。保存前会先测试连接。

托盘图标的右键菜单：打开面板、新建下载、全部开始、全部暂停、设置、开机时启动、退出。

Windows 11 可能把新的托盘图标放在溢出区，可以在「设置 → 个性化 → 任务栏 → 其他系统托盘图标」里让它一直显示。

## 构建

需要 .NET 10 SDK。

```
dotnet build src\Aria2Tray -c Release -p:Platform=x64
```

| 参数 | 作用 |
|---|---|
| `--demo` | 用内置的演示数据运行，不连 aria2 |
| `--debug` | 打开文字调试通道（`%LOCALAPPDATA%\Aria2Tray\debug-cmd.txt` 和 `debug-result.json`） |
| `--lang=en`、`--lang=zh` | 只在这次运行里固定界面语言 |

设计说明见 [docs/design.md](docs/design.md)。
